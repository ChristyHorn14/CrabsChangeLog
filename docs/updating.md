# Updating Crabs

## Import into your existing collection

Keep a backup of your Anki collection before updating. Obtain the new package through the existing download form and import it into the collection containing your existing Crabs deck. Do not delete the old deck first as part of this update workflow.

Review Anki’s import options and summary. The packaged-deck importer matches existing notes and can update them depending on modification times and selected options. Your local edits, note types, Anki version, and import settings can affect the result. Package removals do not reliably remove those notes or cards from an existing collection.

The author reports that the June 20, 2026 package was imported into a clean Anki profile, then the September 20, 2026 package was imported over it, and the update behaved appropriately. This is evidence for that tested release pair; it does not establish identical results for every customized collection or future release. The exact Anki version, options, and import summary were not recorded in this repository.

For future releases, review the generated release notes. If your collection has substantial personal changes, test the update in a separate profile or a copy of your collection first. See [Anki’s packaged-deck update documentation](https://docs.ankiweb.net/importing/packaged-decks.html#updating).
